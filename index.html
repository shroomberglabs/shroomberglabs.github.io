About this directory

Useful details. Clear provenance.

Provider records and their source links come from the Shroomberg location audit. Address labels distinguish storefronts, clinics, research sites, mailing addresses, registered offices, facilities, and historical entries. The directory is designed to support additional provider and service types as the dataset grows.

When a provider has no single venue, the listing uses its documented state, province, parish, or operating region. An OSM marker is a map lookup result, not a new address verification. Region-only points represent an area, not a specific provider site.

Data snapshot: —. Blank website fields mean no verified public URL was attached to that record in the audit.
