# Shroomberg Maps

Flat GitHub Pages project folder. Every site file is at this folder's top level; there are no nested folders.

Upload these files to the root of a GitHub repository, then publish the `main` branch root with GitHub Pages. Follow `SETUP_GUIDE.md` to configure `api.shroomberg.com` for the Cloudflare Worker.

The site uses `providers.json` for its public map and search. The source workbook is intentionally not included in this Pages folder because branch-root publishing serves every root file publicly.
